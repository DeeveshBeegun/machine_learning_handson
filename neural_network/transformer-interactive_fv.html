Sequence Models

Recurrent Neural Networks (RNNs)

One token at a time — each step passes a hidden state h forward to the next

📐 Recurrence Formula
ht = tanh(Wh·ht-1 + Wx·xt + b)
Same weights W reused at every step — compact, but sequential.
✅ Where RNNs shone
Language modelling · Sentiment analysis
Early machine translation (seq2seq)
Speech recognition · Time series
⚠️ The core problem
Information from step 1 must travel through every intermediate step to reach step N. Gradients shrink exponentially — the vanishing gradient problem.
Sequence Models

Long Short-Term Memory (LSTM)

Hochreiter & Schmidhuber, 1997 — three gates that selectively remember, write, and forget

🗑 Forget Gate (ft)
σ(Wf·[ht-1, xt] + bf)
Output 0–1: how much of the old cell state to keep.
✏️ Input Gate (it)
σ(…) ⊙ tanh(…)
Decides what new information to write into cell memory.
📤 Output Gate (ot)
σ(…) ⊙ tanh(ct)
Filters the cell state to produce hidden state ht.
💡 Why it helped — and why it wasn't enough
The cell state c flows through with only small changes — gradients survive longer. But processing is still sequential. Long sequences still suffer, and parallelisation on GPUs remains impossible.

🔗 Long-Range Dependency Problem
In a long paragraph, information from the first sentence may be crucial for the last. The initial signal travels through every processing step — it can become very weak or "vanish," making it hard for the model to connect distant words. Path length between positions: O(n) in an RNN.
⚙️ Parallelization Problem
Word N must be processed before word N+1. You cannot process a sentence all at once — making it impossible to take full advantage of modern GPUs and TPUs which excel at parallel computation. Training time on large corpora is prohibitively slow.
✅ The Transformer Solution
Replace recurrence with self-attention — every token directly connects to every other in a single step. Path length: O(1).
Process in parallel — the entire sequence is computed simultaneously, making full use of GPU/TPU hardware.
Scale freely — more data + more compute = qualitatively better understanding. No architectural bottleneck.

Real-World Impact

Transformers Across Domains

The architecture has generalised far beyond NLP

🗣️
Natural Language
ChatGPT, Claude, Gemini — translation, summarisation, question answering, reasoning. ChatGPT reached 100M users in 2 months — fastest adoption of any application in history.
👁️
Computer Vision
ViT, DETR, DALL·E, Stable Diffusion. Images split into 16×16 patches treated as tokens. Outperforms CNNs at scale with 10× less training data when pre-trained on ImageNet-21K.
🧬
Biology
AlphaFold 2 predicted >200M protein structures — covering virtually all known proteins. A 50-year grand challenge solved in months. Sequences treated as tokens; Evoformer is the core attention module.
💻
Code Generation
GitHub Copilot, CodeLlama, StarCoder. Copilot users accept ~30% of suggestions, completing repetitive code automatically. Trained on billions of lines of public code from GitHub.
🎵
Audio & Speech
Whisper (near-human transcription in 99 languages), MusicLM, AudioLM. Audio is tokenised as log-mel spectrograms — the same Transformer architecture, different token type.
🤖
Robotics & RL
Decision Transformer, Gato. Robot trajectories (states, actions, rewards) treated as token sequences. Gato plays Atari, captions images, chats, and controls robots — one model, 600+ tasks.
Summary

6 Things to Remember ✏️

1
Attention replaces recurrence
Direct token-to-token connections. O(1) path between any two positions. All pairs computed in parallel — the key breakthrough over RNNs, which had O(n) sequential steps.
2
Q·K gives scores, V gives content
Query × Key dot product = how relevant each word is. Softmax turns scores into weights. Weighted sum of Values = a context-rich output vector. Scaled by √d_k to stabilise gradients.
3
Residuals + LayerNorm make depth possible
Every sub-layer is wrapped in LayerNorm(x + Sublayer(x)). Without residual connections, gradients vanish and deep stacks fail to train. N=6 encoder + N=6 decoder blocks is the base configuration.
4
Architecture is modular — and generalises
Encoder-only (BERT) for understanding. Decoder-only (GPT) for generation. Encoder+Decoder (T5) for seq2seq. Image patches as tokens (ViT) for vision. One mechanism adapts to all sequence tasks.
5
Pre-training is the universal starting point
Train on billions of unlabelled tokens via next-word prediction (GPT) or masked-word prediction (BERT). The model learns grammar, facts, and reasoning. Fine-tune on labelled data for any downstream task — a 2-stage paradigm that now dominates all of AI.
6
Scale unlocks emergent capabilities — and O(n²) is the frontier
Reasoning, code writing, and in-context learning emerge only at large scale (GPT-3 = 175B params). The cost: attention is O(n²) in sequence length. FlashAttention, mixture-of-experts, and state-space models (Mamba) are the active research frontier.
